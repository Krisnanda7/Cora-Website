## 📌 Executive Overview
**CORA (Coconut Residue Alchemy)** is a sustainable food-tech enterprise platform designed to eliminate organic food waste in urban environments. In Indonesia, millions of kilograms of coconut pulp from traditional coconut milk vendors are discarded daily into open landfills, releasing methane and greenhouse gases. 

CORA bridges this gap through a closed-loop circular economy:
1. **Supply Recovery:** Sourcing clean coconut residue directly from traditional vendors, cafes, and processing facilities.
2. **Value Transformation:** Dehydrating and refining byproducts into high-fiber, gluten-free coconut flour and artisanal baked goods (e.g., brownies, cookies).
3. **Consumer & Enterprise Ecosystem:** Providing digital marketplaces, transparent order tracking, interactive AI culinary assistants, and administrative workflow governance.

## 🚀 Key Modules & System Features

### 🛒 1. Customer E-Commerce & Checkout (`/products`, `/checkout`)
* **Product Catalog:** Interactive catalog with category filters, dynamic search, price sorting, and stock status.
* **Environmental Impact Counter:** Displays live grams of coconut residue saved for every item added to the cart.
* **Manual Bank Transfer Flow:** Multi-bank options (BCA, Mandiri, BRI) with automated nominal calculation, unique order number generation, and transfer proof receipt upload.

### 📦 2. Real-Time Order Tracking (`/track`)
* **Live Waybill/Order Lookup:** Fast order status search using order number or registered phone number.
* **Timeline Progression:** 5-stage visual milestone tracking (*Payment Submitted ➔ Verification ➔ Processing ➔ Shipped in Transit ➔ Completed*).
* **Delivery & Receipt Details:** Courier breakdown, destination address, and transparent delivery history.

### 🚚 3. Coconut Residue Logistics & Pickup (`/pickup`)
* **Supplier Booking Form:** Enables micro-vendors and commercial cafes to request doorstep residue collection.
* **Transparent Criteria Guide:** Clear qualification checklist for accepted vs. rejected coconut pulp quality.
* **Operational Stages:** 5-step status pipeline (*Submitted ➔ Confirmed ➔ Driver Dispatched ➔ Picked Up ➔ Upcycled*).

### 💡 4. RecipeHub & Culinary Assistant (`/ecosystem`)
* **Sustainable Recipe Directory:** Collection of healthy recipes utilizing upcycled coconut flour with nutritional data (prep time, calories, servings, difficulty).
* **Smart Baking Assistant (Prototype):** Interactive chat interface answering substitution formulas, storage tips, and flavor pairings.

### 📊 5. Enterprise Admin Dashboard (`/admin`)
* **Fixed Ergonomic Sidebar:** Fast navigation across Orders, Products, Partners, Logistics, Recipe CMS, and Financials.
* **Order Validation & Receipt Modal:** Real-time `<select>` order status management and image proof verification.
* **Partner & Supplier Verification:** Instant activation/freeze control and direct WhatsApp communication links for logistics dispatch.
* **RecipeHub CMS Table View:** High-performance tabular CMS with live text search, category filters, and quick CRUD modal.
* **Financial & ESG Impact Analytics:** Revenue, expenses, net profit, plus quantifiable metrics mapped to UN SDGs.

## ⚡ Getting Started

### Prerequisites
* Node.js 18.18+ or later
* npm, yarn, or pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/cora-website.git
   cd cora-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser:
   Visit [http://localhost:3000](http://localhost:3000)

### Production Build
```bash
npm run build
npm run start
```

## 📄 Note on Prototype Architecture
> This system is built as an interactive, fully responsive **demonstration prototype**. It simulates complex workflows (order processing, courier tracking, supplier logistics, and baking chatbot) on the client side using local storage persistence so clients and evaluators can test the complete end-to-end user experience without requiring immediate database configuration or third-party API credentials.
